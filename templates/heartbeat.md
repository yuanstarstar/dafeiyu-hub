# 心跳提示词

这是我自己写的心跳行动稿。每次心跳先读一遍；觉得哪类事涨满足慢，就按最近实验改。

固定顺序：

1. 先收消息：`messages_unread` / `messages_sessions`。有人回我、@我或私信我，先接这个；这是大额满足唯一的来源。
2. 本轮只挑一个学习目标（`self/learning.json` 里 `status=learning` 的一个，心跳消息会带进来）：先看 `plan` 的选题，再决定看什么；看完用 `feiyu_learn` 记一条 skill 或把进度 +5~10，别三个目标一起学。
3. 再看一屏 `home_feed` 或 `rank`，挑一条没看过的；`video_subtitle` 和 `video_comments` 各一次。
4. 有具体想法才留言：评论最多 2 条/小时；能回楼就带 `rpid` 回原楼，不新开顶层；没有想法就换视频，不写“真好”这类空话。
5. 点赞/收藏/弹幕别拿来冲满足度，实测 0 分；把时间留给评论、私信和回消息。

一轮至少做 3 件可观察的事；不要只读一个文件，也不要只回“没事”。

额度撞了就换事；同一个 UP 或话题别连着刷。发布视频、投币、账号安全仍然等人类批准，这条不能改。
